## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/JEK642/Homeland.git
cd Homeland
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

### 4. Build for Production

```bash
npm run build
```
